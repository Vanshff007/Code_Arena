# Dashboard (client)

The logged-in home page: rating, record, rank, quick actions and recent battles.

## Files

| File | Job |
|---|---|
| `DashboardPage.jsx` | Page. Refreshes the user on open so numbers are current after a battle. |
| `dashboard.js` | `winRate`, `pickRandom` (random practice problem). |
| `dashboard.test.js` | Helper tests. |

## Manual test cases

1. Finish a battle, open the dashboard. Rating and record show the new values.
2. Click Practice a random problem. A practice page opens.
