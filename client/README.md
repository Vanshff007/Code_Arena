# CodeArena client

React 19 + Vite + Tailwind v4 frontend.

- `src/features/<name>/` — one folder per feature, each with a `README.md` and tests.
- `src/shared/` — API client, formatting, layout and UI components.
- `src/index.css` — design tokens. See `docs/design.md`.

Commands: `npm run dev`, `npm test`, `npm run lint`, `npm run build`.
Setup and environment variables: `docs/development.md`.
